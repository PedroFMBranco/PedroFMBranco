### Hi, I'm Pedro

CTO and Head of R&D at [Weezie](https://weezie.io) in Porto, where we build GIS software that telecom operators use to plan, build and run fibre networks. I joined as a full-stack engineer in 2016, have been CTO since 2018, and still build.

- **Day to day:** Laravel, Vue 3, TypeScript and Node, PostgreSQL/PostGIS, Python, AWS, Kubernetes.
- **R&D:** automated fibre network design, real-time map sync, and AI coding agents on production software: written plans, tests first, review before merge.

Most of my work lives in private company repos. What's public:
